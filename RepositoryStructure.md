# This file describes the nesting of folders in this repository and software used for design


# Folders and Files

1) INSTRUCTIONS - Folder with comprehensive set of instructions for the end user to assemble this model kit.
2) DESIGN - Document containing the specifications and constraints of the radio, as well as the design process for it.
3) Electronics - Schematics PCB designs in KiCad format.
4) BOM - Bill of Materials in .ods format.
5) Code - Software for the microcontroller that regulates the local oscillator.
6) Enclosure - Design files for hardware casing.

# Software Used

1) KiCad - For the design circuit schematics and PCB designs
2) LTspice - For circuit simulation
