# This file describes the nesting of folders in this repository and software used for design


# Folders

1) INSTRUCTIONS - folder with comprehensive set of instructions for the end user to assemble this model kit
2) SPECS - technical specs of the radio, such as frequency, power consumption, components price and etc.
3) PCB_Designs - KiCad formatted PCB designs
4) Circuit_Schematics - KiCad formatted schematics
5) Microcontroller_Code - software and instruction for operating microcontroller that regulates local oscillator
6) Enclosure_Design - schematics for hardware casing
7) Parts_List - .ods formatted parts list with price tags and vendors


# Software

1) KiCad - used to design circuit schematics and PCB designs
2) LTspice - used for circuit simulation
